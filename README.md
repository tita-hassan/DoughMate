# DoughMate (שם עבודה)

כלי לתכנון אפיית לחם מחמצת: מה אופים, מתי, ואיך, ואחר כך ליווי שלב אחרי שלב עם טיימרים וצ׳קליסט.

## ארבעת השלבים
1. **מה? מתי? איך?** – בחירת מתכון וכמות, עוגן הזמן (סוף אפייה / תחילת אפייה / סוף תפיחה / מחמצת בשיא) ושלבי ההכנה.
2. **האכלת מחמצת** – כמה האכלות בשיא לפני התהליך, שעה לכל האכלה, טיימר המתנה בין האכלות.
3. **הכנת הבצק** – אוטוליזה/פרמנטוליזה, קיפולים, Poke Test, עיצוב, תפיחה.
4. **אפייה** – חימום, Oven Spring, בדיקת 95°, קירור על רשת.

## מבנה
- `design/` – מסכי העיצוב (קנבס Claude Design, קבצי `.dc.html` + `canvas.json`).
- `app/index.html` – האפליקציה העובדת (קובץ HTML יחיד, שמירה ב־localStorage): תכנון, האכלות, בצק, אפייה, מתכונים, הגדרות וטבלאות חישוב.
- `prototype/index.html` – פרוטוטיפ עובד (HTML בקובץ אחד, שמירה ב־localStorage).

## החלטות
- בכל מתכון: מצרכים קודם, אחר כך אופן הכנה (שיטה, לישה, קיפולים, צורת אפייה, זמן אפייה אחד או מחולק).
- ההגדרות הן ברירות מחדל לכל המתכונים; מתכון יכול לקבוע ערך משלו.
- הלוגו והשם עדיין פתוחים.

- טבלאות החישוב (שעות לפי טמפרטורה, יחס האכלה וסוג קמח) ניתנות לעריכה, ולוח הזמנים נגזר מהן.

- מסך התכנון הוא שלוש כותרות (מה? מתי? איך?) שנפתחות בלחיצה, כל אחת עם אנימציה קצרה: ספר שנפתח למתכונים, שעון מחוגים שמסתיים בשעה שנבחרה, להגדרות הזמן, וצנצנת מחמצת עם כף שמאכילה ומערבבת. האנימציה רצה רק ברגע הפתיחה.
- שאלון פתיחה במקום מסך הגדרות מלא. השאלה הראשונה: "יש לך כבר שיטת עבודה שאתה רגיל אליה, או שאתה צריך עזרה?". מי שיש לו שיטה עובר על כל פרט (כ־15 שאלות, חלקן מותנות בתשובות קודמות). מי שצריך עזרה עונה על ארבע שאלות כלליות, ושאר ההגדרות מקבלות ברירת מחדל. הכול ניתן לעריכה במסך ההגדרות.
- בשלב הבצק לכל פעולה יש אנימציה משלה: מלחייה מפזרת מלח לקערה (טיימר המלח), קיפול בצק במבט מלמעלה (טיימרי הקיפולים), ואצבע שלוחצת על הבצק בבדיקת Poke Test. ההמתנות (תפיחה ראשונה, מנוחת ספסל, תפיחה סופית) נשארו עם הקערה שבה הבצק תופח. אנימציות הטיימר רצות רק כשהטיימר רץ.
- עוד אנימציות בשלבי העבודה: האכלת מחמצת (כף שמוזגת ומערבבת בצנצנת), Pre-shaping (כף בצק שנאספת לכדור), מנוחת ספסל (שלושה כדורי בצק שמכוסים במפית מקומחת), Shaping (בצק שנכנס לסל תפיחה), ותפיחה קרה (קערה שנכנסת למקרר והדלת נסגרת). תפיחה חמה נשארה עם הקערה.
- פרמנטוליזה: מחמצת, אחר כך מים, אחר כך קמח וערבוב. אוטוליזה: מים וקמח וערבוב, ובשלב המלח נוספת המחמצת ואחריה המלח. הקיפולים הם ארבע משיכות בכל סבב: מ־12 ל־6, מ־3 ל־9, מ־6 ל־12 ומ־9 ל־3. Pre-shaping: יד מכנסת בצק מבולגן לכדור. Shaping הוא שלב אחד: יד מעצבת כיכר ומניחה אותה בבנטון. בתפיחה קרה הבנטון נכנס למקרר מכוסה.
