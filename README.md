# DoughMate (שם עבודה)

כלי לתכנון אפיית לחם מחמצת: מה אופים, מתי, ואיך, ואחר כך ליווי שלב אחרי שלב עם טיימרים וצ׳קליסט.

## ארבעת השלבים
1. **מה? מתי? איך?** – בחירת מתכון וכמות, עוגן הזמן (סוף אפייה / תחילת אפייה / סוף תפיחה / מחמצת בשיא) ושלבי ההכנה.
2. **האכלת מחמצת** – כמה האכלות בשיא לפני התהליך, שעה לכל האכלה, טיימר המתנה בין האכלות.
3. **הכנת הבצק** – אוטוליזה/פרמנטוליזה, קיפולים, Poke Test, עיצוב, תפיחה.
4. **אפייה** – חימום, Oven Spring, בדיקת 95°, קירור על רשת.

## מבנה
- `design/` – מסכי העיצוב (קנבס Claude Design, קבצי `.dc.html` + `canvas.json`).
- `app/index.html` – האפליקציה העובדת (קובץ HTML יחיד, שמירה ב־localStorage): תכנון, האכלות, בצק, אפייה, מתכונים, הגדרות וטבלאות חישוב.
- `prototype/index.html` – פרוטוטיפ עובד (HTML בקובץ אחד, שמירה ב־localStorage).

## החלטות
- בכל מתכון: מצרכים קודם, אחר כך אופן הכנה (שיטה, לישה, קיפולים, צורת אפייה, זמן אפייה אחד או מחולק).
- ההגדרות הן ברירות מחדל לכל המתכונים; מתכון יכול לקבוע ערך משלו.
- הלוגו והשם עדיין פתוחים.

- טבלאות החישוב (שעות לפי טמפרטורה, יחס האכלה וסוג קמח) ניתנות לעריכה, ולוח הזמנים נגזר מהן.
